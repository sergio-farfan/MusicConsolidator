# Security Policy

This app runs entirely on your Mac. It has no network access, no accounts,
and no telemetry; it talks only to your local Music.app through Apple
Events, and every library write is planned, user-confirmed, and verified by
readback.

## Reporting a vulnerability

Please report suspected vulnerabilities privately via
[GitHub Security Advisories](https://github.com/sergio-farfan/MusicConsolidator/security/advisories/new)
rather than public issues. Reports are read by the author and acknowledged
as quickly as possible.
